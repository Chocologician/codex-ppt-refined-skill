# 用户提供的素材

用于论文图、实验图表、截图、照片、标志等必须使用的原始素材。这些是严格输入，不只是视觉灵感。

源素材可放 assets/figures/、assets/logos/ 等目录，origin_image/ 只放最终 slide_XX.png 页图。大纲逐页记录精确路径、用途及保真要求，本地可渲染素材使用 Markdown 图片引用，方便核对。

## 使用要求

- 保持已选择后端，不因有源图就随意切换。
- 使用所选工具支持的参考图或编辑输入，确保每份必需素材实际被传入。
- 内置模式需要先查看本地图像，使其在当前上下文中可见；附件或已生成图片亦需清楚标注用途。
- view_image 用于查看，不代表生图工具自动收到文件路径。提示中区分严格素材与仅供风格参考的图片。
- 实验图保留数值、坐标、标签、图例、颜色、曲线与箭头，只设计周围版式。
- 除非用户明确要求风格化重绘，不要求模型“想象相似图表”替代证据。
- 完成后逐图检查。不能使用必需素材的路径应报告缺失能力，而不是只用文字生成替代页。

可在任务的 source_assets 中写 path、usage 与 fidelity，在 constraints 中明确“使用原图，不重绘，不修改数据”。字段保持现有任务格式，说明值使用任务语言。

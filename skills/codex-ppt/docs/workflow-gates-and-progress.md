# 图片式制作阶段与进度

在创建下游文件、进入下一阶段或报告进度前阅读。只适用于图片式制作，不重新阻断已认可稿件的动画调整。

## 阶段

依次明确资料与素材、大纲、视觉方向、生图后端、一页样张、全篇生成、质检与组装。已有明确批准或用户要求跳过确认时，不重复提问；未获必要选择时，不先做后问。

大纲认可前，不生成最终 deck_spec.json、speech.md、图片任务与成品。必要内部规划使用带 .draft. 的名称并标明草稿。包含必需图表时，在大纲阶段核对页面与素材映射。

## 完成证据

| 阶段 | 证据 |
| --- | --- |
| 内容准备 | 认可的大纲、页面素材映射与后端决定 |
| 样张 | 指定页面的最终图片及认可记录 |
| 任务准备 | prompts/slide_XX.json、slide_jobs.json、slide_run_state.json |
| 分派 | 状态脚本中记录的代理与页面对应 |
| 结果 | record_slide_result.py 记录的图片来源与生成方法 |
| 组装 | 全部最终页图、检查结果、最终讲稿与有效PPT文件 |

复杂任务可显示这些步骤的简短进度，保持一个当前步骤。不能仅依据聊天描述把步骤标成完成。

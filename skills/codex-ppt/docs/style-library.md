# 可复用风格库

当用户要求保存样张、成稿或参考文件的风格时使用。保存的是视觉系统，不是当前资料内容。

## 查看与提取

以实际可见页面为依据，PDF/PPT先渲染再看。覆盖封面、普通正文、流程/数据和结尾，必要时记录分区变化，不能只看封面或XML。

记录短名称、适用场景、视觉方向、画幅、背景、信息密度、留白、配色及用途、文字层级、构图模式、图像处理、允许与避免元素、渲染约束。

提炼2–4个可变布局作为候选，不把同一个构图重复到每页。避免保存业务数据、人名、论文结果、私人项目、原文长段或必须依赖的源图片。品牌风格只在用户明确要求时保存。

## 位置与命名

个人风格位于 ${CODEX_PPT_HOME:-~/.codex-ppt-skill}/references/，在技能安装目录之外，更新时保留。名称简短、表达视觉特征，例如“深色数据科技风”“柔和学术插画风”，不按客户或临时项目命名。

目录不存在先创建。同名个人文件先明确合并、替换或另取名；与内置风格同名时说明个人风格优先。没有覆盖授权时不要覆盖。

## 文件结构

沿用 references/ 的现有结构，以中文说明适用场景，并提供兼容的结构化描述。字段保持 style_name、best_for、visual_direction、canvas、color_palette、typography、layout_patterns、layout_usage_rule、layout_blueprints、visual_elements、image_treatment、rendering_constraints。

描述值可以使用中文。保持文件自包含，不依赖私人截图。单次使用风格无需创建永久文件。

## 发现与交付

通过扫描个人目录发现，不把个人风格加入技能内置列表。公共风格通过仓库贡献流程进入 references/，两者用途不同。

保存后告知名称、实际路径、安装目录外保存及调用方式，例如“以后可以说：用‘深色数据科技风’做这份演示文稿”。

# 生图后端选择

在确认后端、生成第一张样张之前阅读。优先使用当前可调用的内置图片生成或编辑工具；只有无法满足必需能力、实际失败或用户明确要求时，使用 scripts/image_gen.py 后备方案。

## 决策

先检查实际可调用工具，不按代理名称、订阅类型猜测。分辨率、质量、编辑或本地文件管理需求本身不意味着必须换后端，先看工具实际参数。

环境未提供证据时，不声称内置工具使用某个确定模型。成功出图也不能证明模型、尺寸或质量参数按要求生效。需要精确选择但工具不暴露参数时说明限制，按用户需求选择可用方案。

不要因为批量方便、能直接指定输出路径或能复用本地配置而切换后端。后端确定后，样张和工作者保持同一生成路径。

## 确认与配置

首次出图前简述检查了什么、使用哪个后端、为什么需要或不需要后备方案。按已有授权继续；缺少必要选择时再确认。

内置模式可说明：“当前可调用内置生图工具，准备使用它制作一页样张。”

后备模式可说明：“内置工具不可用或缺少必需能力，使用已选择的接口/命令行后备方案。”

后备脚本自动加载共享运行目录的 .env。先正常运行，不手动解析 .env，不提前索要密钥。只有有意选择后备方案后报配置或鉴权错误，或用户明确要改设置，才读取[模型配置](image-model-configuration.md)。

选定后备方案后阅读[命令行操作](cli-api-fallback.md)。不要在内置工具可用且满足任务时以缺少 OPENAI_API_KEY 为由停止制作。

# 公开可复现演示

这是三页合成的原生排版与动画功能示例，内容和视觉素材由本项目制作，按仓库 MIT 许可提供，不含个人资料或第三方图片。源稿使用 Artifact Tool 创建；重放动画只需要本仓库与桌面 PowerPoint，不需要该创建工具，也不调用生图接口。

它演示可编辑对象、组件分组、流程逐步展开和保存后时序验证，不宣称是图片生成模型的效果样片，也不证明任意图片都能自动转换为可编辑PPT。

## 文件

- [可编辑源稿](source.pptx)：三页，尚未添加页内动画。
- [动画成品](animated.pptx)：与源稿同样的最终画面，包含16个进入效果。
- [动画计划](animation-plan.json)：与该源稿绑定的哈希、形状编号、分组与时序，无需手工修改即可重放。
- [核验记录](verification.json)：文件校验值、页数、效果数量、时序与画面对比的实际结果。
- [合成内容提纲](brief.md)：可提供给代理进行从零制作练习；不同生成工具不会保证相同画面。

## 重放动画

在仓库根目录的 PowerShell 7 中运行：

    ./examples/public-demo/run_demo.ps1

成功后输出一个新的构建目录，包含 animated.pptx 和 audit.json。源稿保持不变。打开生成的PPT并按 F5：每页自动展开，单击进入下一页。第二页约7.65秒展开完整流程。

没有桌面 PowerPoint 时，可以直接查看静态图片和动图，不要将网页查看器不播放原生动画误判为文件内容缺失。

## 核对结果

检查三页内容完整、文字可编辑；第二页按四个步骤顺序出现，最后呈现底部结论。执行器会自动核对保存后时序，完整画面与源稿应一致。不同机器的字体和抗锯齿可能产生渲染差异，像素结果只说明记录中指定环境的同渲染器对比。

## 修改练习

熟悉流程后，可复制源稿修改文字，再重新清点形状并建立新计划；源文件变化后不要继续使用旧哈希。新增效果或调速时，在新输出目录中操作并保留原稿。

# 测试说明

| 层次 | 方法 | 覆盖范围 |
| --- | --- | --- |
| 静态 | 单元测试、链接、格式与来源清单 | 结构、文件校验、说明引用与语法 |
| 合成稿 | Windows 桌面 PowerPoint | 分组、时序、隐藏页、静态画面与异常输入 |
| 内容与放映 | 同条件前后对比、实际放映 | 特定稿件的清晰度、美观、事实和讲述节奏 |

各层不能互相替代。静态测试不依赖密钥和网络。真实图片调用可能收费，仅在明确需要时运行。

## 命令

```shell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
```

```powershell
./skills/codex-ppt/scripts/test_refined_animations.ps1
```

合成稿使用独立构建目录，不修改个人稿件。目前未覆盖交互、并行、媒体与退出动画。

## 公开示例

仓库包含[三页合成演示](../examples/public-demo/README.md)。静态测试检查源稿与计划绑定、文件校验、原生文字未丢失及原生动画结构。使用其中的 run_demo.ps1 可在支持环境重放，核验记录随文件提供。

源稿是项目创建的公开测试素材，不是私人稿件，也不用于证明生图模型效果。

## 验证记录

写明环境与版本、命令与结果、材料来源、实际检查范围。视觉改动给代表页前后截图，动画说明触发、展开时间与实际放映情况。未运行的检查写明原因，不把“未发现问题”写成“全部兼容”。

新增回归优先复现真实失败，断言能区分正确与错误行为，不只匹配标题。新格式、效果或平台同时覆盖成功与关键失败。使用最小必要的公开授权或合成材料，保留来源。

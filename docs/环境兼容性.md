# 环境兼容性

“能读取技能文件”“能编辑PPT”“能播放原生动画”是不同能力，不能相互推断。

| 功能 | 条件 | 已有验证 | 未验证或不支持 |
| --- | --- | --- | --- |
| 仓库静态检查 | Python 3.10及以上、开发依赖 | 本地检查；持续集成配置提供跨平台静态检查 | 不证明图像质量或桌面放映 |
| 统一Python入口 | Python及共享运行目录 | 解释器路径、参数和本地帮助命令 | 不自动保证所选图片服务可用 |
| 原生动画执行 | Windows、PowerShell 7、桌面PowerPoint | 合成稿与公开三页示例，环境记录随示例提供 | macOS、Linux、网页版、WPS未验证 |
| 可编辑重建 | 代理提供原生演示文稿编辑工具 | 流程与原生示例 | 没有独立转换引擎，也没有全部代理兼容承诺 |
| 内置生图 | 当前代理实际提供图片生成/编辑工具 | 按任务检查，不能只靠代理名称判断 | 本仓库示例不证明某个模型效果 |
| 图片接口 | 兼容的后端、模型和配置 | 继承上游适配代码，实际调用需单独确认 | 不把静态测试当作服务兼容测试 |

公开示例的 [verification.json](../examples/public-demo/verification.json)记录本次原生演示的环境和检查结果，不作为通用支持认证。

新平台贡献应注明版本、复现步骤、输出差异、实际检查范围。没有测试过的环境保持“未验证”，不因理论可用升级为支持。

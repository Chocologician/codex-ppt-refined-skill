# 初次贡献任务

以下是可以直接着手的小任务，不代表已经创建了对应的线上问题。

## 增加一个失败样例

用公开或合成内容复现标题溢出、中文换行或信息过密等一个问题。按案例模板写复现条件、预期与实际结果。

修改位置：examples/ 下的新目录与案例说明。验收：别人不依赖聊天背景也能理解输入、重现问题，素材有来源，未上传私人资料。

## 检查一种环境

在另一版本的 Windows、PowerShell 或 PowerPoint 中运行公开示例，记录实际结果，不直接承诺兼容。

修改位置：环境兼容性文档，附精简测试记录。验收：版本、命令、结果与未覆盖部分清楚；不能只写“我这里正常”。

## 改善一个页型

选择正文、复杂流程或数据页，按相同内容与尺寸比较两种排版，解释阅读顺序改善在哪里。

修改位置：风格文档或公开案例。验收：有同条件前后图，至少指出一条可复用规则与一个不适用条件，不把个人偏好直接设为全局默认。

## 增加一项有意义的回归

复现一个现有脚本真实失败，再添加能区分正确和错误行为的测试。优先使用合成输入，避免付费服务依赖。

修改位置：tests/ 或对应执行器测试。验收：修复前会失败、修复后通过，失败原因与用户问题对应，不只是匹配某句说明。

提交前阅读[贡献指南](../CONTRIBUTING.md)。尚不确定范围时先提交功能提案，不需要先完成一个大功能。
